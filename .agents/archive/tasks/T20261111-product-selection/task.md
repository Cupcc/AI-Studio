# 选品工作台

## 范围与来源

2026-11-11 用户要求参考 EnterpriseAI/apps/web 构建选品工作台，并明确真实 Agent 执行、复用已有 Provider、支持 Codex CLI。交付为 AI Studio 标准网页插件模板，经添加入口创建项目实例。

实现四流程（来源整理、分析、候选、设计）、节点要求与依赖、真实 Codex 会话、流式结果、停止与审批入口、候选比较入选及状态保存。复用 SessionService，不新增 CLI 进程管理器。本期设计结果为真实文本说明与产物路径，不包含图片绑定/预览；不以原型合成图片冒充生成。

## 验收

- 从添加工作台入口创建、预览并添加选品模板，关闭重开保留状态。
- 修改任务与来源，按节点生成及依赖顺序编排；上游修改提示下游过期。
- 节点执行走真实 Codex Provider，展示输出、失败、停止与需输入，已有成果和执行历史保留。
- SDK 校验能力与工作台/Project 会话归属；关闭页面不停止已有 Session。
- 类型检查、直接单测、Electron UI、真实 Codex 和独立评审。

## 实施决定

- 使用现有标准 HTML/CSS/JS 网页包。选品为可添加模板，不强加到每个项目的默认导航。
- 页面节点业务与通用 Agent SDK 分开。Session 是执行事实来源，页面保存业务配置、节点到会话的关联及已采纳结果。
- 按原型约定，页面重新打开不会自动继续未发起的排队工作；已有会话仍可读取。

## 交付边界

- 使用真实 Codex 文本/结构化输出；图片文件绑定和页面图片预览未交付。
- 外部调研真实性、真实商品商业效果及真实图片工具调用未作为本次合成资料验证结论。
- 持久保存的是节点配置、已采纳文本与 Session 执行映射；页面离开时停止发起后续排队节点，不是持久后台工作流调度。
