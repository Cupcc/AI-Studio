# 集成计划

## Worker

| Worker | 职责 | 写入范围 | 集成方式 |
|---|---|---|---|
| Main Agent | 保全工作、修正集成缺陷、拆分提交、验证、合入与收尾 | 应用与 Adapter 修复、集成任务、相关记录 | 独立 worktree 顺序实施 |
| Review Agent（cli-review） | 独立检查 Codex 运行中发送的跨模块变更及必要模拟场景；未参与实现 | 本任务 `acceptance.md` | Main 修复完成后复核；不运行真实模型调用、不占用 Electron 窗口 |

## 顺序

1. 整理 CLI / 职责文档与历史结论回写、v04 原型，保留未完成事项。
2. 修复运行中发送错误传播与消息持久化风险，基础检查与独立复核。
3. 提交设置 worktree、rebase 集成分支，解决重复原型和文档冲突。
4. 最终回归、界面检查、快进 main、推送并检查 CI，更新集成结果。
