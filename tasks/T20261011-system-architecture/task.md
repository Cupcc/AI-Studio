## 状态口径

- 建设完成：节点所列授权实现与必要技术验证完成，人工功能验收由负责记录另行说明。当前 HTML 沿用 2026-10-19 的技术范围口径，不将绿色等同于人工接受。
- 建设中：已有代码，尚需补齐、验证、人工新增体验验收或后续发布；不表示当前有人正在编码。
- 未建设：尚无对应功能实现；方案、导航或占位容器不算完成。
- 外部依赖不计建设数量；P1 单列。数量只表示图中节点分布，不表示产品完成百分比。
- 已签收的模拟核心流程证据独立注明；不将它外推为真实 CLI 或整体模块完成。
- 任务状态按下一步由谁行动划分：待验收（你体验功能）、待评审（你审阅文档或作产品、发布决定）、待推进（AI 在授权内实现、检查或验证）、未建设（后续阶段）。AI 技术评审与检查归入“待推进”，不归入“待评审”。状态直接记录在任务数据中，描述说明进展与前置条件；已完成结果和范围限制单列。此处是路线图与负责任务的展示快照，不代替其状态维护。

## 设计方案

- 颜色：纸白 `#f7f9fc`、墨蓝 `#172b46`、蓝色 `#315fbb`、完成绿 `#207451`、建设橙 `#9b5b12`、规划灰 `#56677e`（自检后加深，满足状态文字对比度）。
- 字体：系统 Avenir Next / PingFang SC，中文为主体；代码路径用系统等宽字体，无远程字体。
- 布局：左对齐标题与状态筛选；主体是分层进程画布，右侧模块详情；另有数据流与模块清单。移动端详情下移、画布独立滚动。

```text
标题 / 快照依据                         导出打印
状态筛选 / 搜索 / 视图切换
┌── Renderer UI ──────────┐ ┌─ 模块详情 ─┐
│       Preload IPC      │ │ 状态与边界 │
│   Application Services │ │ 依赖与来源 │
│   Runtime / 工具隔离   │ └────────────┘
│    本地数据与本机 CLI   │
└────────────────────────┘
```

设计复核：以进程边界、调用关系和待建链路作为视觉主体；不采用大数字进度仪表盘。节点统一形态表达同类组件，分组框表达运行边界；状态同时使用文字、图形和颜色。
