## 技术决定

| 决定 | 依据 | 决策者 / 日期 |
|---|---|---|
| 毛玻璃用 macOS 原生 vibrancy（`BrowserWindow` 材质），网页背景透明；纯色移除材质并设该模式的窗口底色；切换在运行时完成 | v04 原型说明“真实的跟随桌面与窗口失焦变暗需用原生 vibrancy 实现”；Electron 44 提供 `setVibrancy` | AI，2026-10-12 |
| 颜色模式写入 `nativeTheme.themeSource`，深浅色读 `shouldUseDarkColors`；替代早先“固定浅色”的决定 | `themeSource` 取值与三种模式一致，并同时驱动原生材质、菜单、对话框与 `prefers-color-scheme` | AI，2026-10-12 |
| 偏好保存在 SQLite `app_meta`（主题、背景颜色、模式三个键），应用级、所有窗口共用 | 已有应用级键值表，无需迁移 | AI，2026-10-12 |
| Renderer 在首次渲染前读取外观并写入 `<html data-theme data-scheme data-glass-color>`，之后以 IPC 事件为准 | 避免重启后先显示另一种外观；不改页面地址，E2E 对入口地址的校验保持不变 | AI，2026-10-12 |
| 布局 Token 共用；颜色与容器背景用语义 Token，按主题 × 模式分四块覆盖；毛玻璃的几何差异集中在 `shell.css` 末尾 | tokens.css 约定“视觉取值集中在一个文件” | AI，2026-10-12 |
| E2E 在主进程中覆盖 `nativeTheme.prefersReducedTransparency` 与 `shouldUseDarkColors` 模拟系统状态，产品代码不加测试开关 | 不能在自动化中修改用户系统设置；E2E 结果不受本机深浅色影响 | AI，2026-10-12 |
| 毛玻璃背景颜色由页面绘制（模糊渐变 + v04 玻璃色 + 细颗粒），以 85% 不透明度叠在原生材质上 | 原生材质只模糊窗口后方的内容，桌面为灰色时整窗发灰；保留少量透出，仍是毛玻璃 | AI，2026-10-12 |
| 深色毛玻璃次要文字提高到 #b0b0b0 | 以比实测更亮的 #404040 代替深色材质时，原定 #a6a6a6 只有 4.27:1 | AI，2026-10-12 |
| 设置对话框高 440 → 520 | 增加“模式”一行后内容超出 440 | AI，2026-10-12 |
| 原生截图按窗口 ID 截取（`screencapture -l`） | 按屏幕区域截取曾两次拍到用户的其他应用（已删除）；窗口 ID 只含本应用像素 | AI，2026-10-12 |
