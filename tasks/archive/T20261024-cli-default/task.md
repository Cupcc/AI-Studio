- 修复：识别新状态并报告 `logged_in / api_key`；显式未登录优先判断，避免 `Not logged in` 在退出码 0 时误判；超时、非零退出的正向状态和未知输出仍失败。不保存认证输出或凭据，不改用户配置。
- 开发者自检（Main Agent，macOS，本次未提交的 Adapter diff）：新增 20 个 stdout / stderr 参数化回归；修复前 4 项失败（新状态及退出码 0 的未登录，各两个输出通道），修复后 Adapter 19 个测试文件 / 277 项全部通过，Adapter 类型检查和构建通过。测试同时检查身份 / key 不泄露、未知版本仍为 `untested`，且仅调用版本与登录检查、不启动模型 Runtime。
