## 1. 推荐结论

**统一底部输入框，把模型与思考强度作为紧邻的下一轮设置，附件单独成行。** 保留现有毛玻璃、字体、720px 消息列和消息滚动规则，集中解决操作位置与信息层级。

New Chat 居中并非违反旧规格：[Shell Spec v02 §6](components/shell-spec-v02.md#6-conversation) 于 2026-10-10 确认了居中方案。本次是根据新的使用反馈提出修订，不能把既有实现写成规格缺陷。

贴底的收益是 New Chat → 第一条消息 → 继续回复，以及切换 Session / View 时，输入区始终在同一位置。代价是空画布更疏，欢迎语与输入框距离增加；本产品是持续处理项目和多会话的工作台，操作位置稳定更适合这一工作流。欢迎语保留在正文区中部，不再参与输入区定位。

## 4. 布局方案

```text
New Chat 正文：              已有 Session 正文：
       今天要做什么？         消息从顶部开始，独立滚动
       当前项目执行位置       打开历史时定位最新

共用底部输入区（主列最大 720px，左右与消息列对齐）
┌────────────────────────────────────────────────────┐
│ 描述开发需求，或继续回复…                           │
│ [当前 View ×] [文件 ×] [图片 ×]  ← 有内容才出现     │
│ +                    模型⌄  思考·默认⌄  [停止] [↑] │
└────────────────────────────────────────────────────┘
```

- 输入区距内容面板底边 20px；内容面板延续 v04 的窗口边缘留白。New Chat 与 Session 的位置、宽度和控制顺序相同。
- 文本沿用最多 8 行自动增高；标签增多时可以向上占用空间。稳定的是底边和工具顺序，不承诺任意内容下总高度不变。
- 标签独立换行，原型标签区最高 90px（三行）后内部滚动；长路径截断并保留完整提示。增加附件不会把模型或发送推到下一行。
- 左侧加号；右侧按“模型 → 思考强度 → Stop（运行时）→ Send”排列。模型与思考间距 2px，动作按钮间距 6px；窄列收紧到 0 / 4px。
- 360px View 列中工具行不换行；长模型名省略，完整值在菜单和提示中可读。默认不收进“更多”，避免多一次操作。
- 普通主列菜单宽 220px；窄列约 202px，锚定按钮上方并约束到列内。生产实现需要处理窗口边缘碰撞与短窗口高度。
- 主列和 View 列共享控制结构；View 使用现有列内边距，不要求两个宽度不同的区域拥有相同屏幕坐标。
- “回到最新”、消息顶部对齐、阅读位置、后台完成提醒继续遵循已有规格；本轮不修改。

## 5. 思考强度与提示状态

视觉名称使用“思考强度”，底部控件显示“思考 · 当前值”。模型和强度分别持久化到当前草稿 / Session，不作用于其他对话。

| 状态 | 建议呈现 | 行为约束 |
|---|---|---|
| 默认 | “思考 · 默认”；菜单默认项旁“沿用 CLI” | 默认不等于固定 medium，也不叫“自动”；生产默认复位遵循 input / Adapter 的 null 契约 |
| 有目录 | 菜单列出当前模型支持的档位，当前项勾选；标题“下一轮生效” | low / medium / high / xhigh 可映射为低 / 中 / 高 / 极高；其他值保留，不凭空增删档位 |
| 切换模型后旧值未列出 | 控件保留旧值，菜单提示“已保留…（目录未列出）” | 不静默改回默认；只有原生返回才能证明不能调用 |
| 模型不提供强度，且无保存值 | 不显示强度控制 | 不呈现空菜单；若有旧值仍须提供说明和复位入口，不能悄悄隐藏选择 |
| 目录读取失败 | 保留当前值，选择暂不可用；辅助提示说明失败与恢复方式 | 不因目录失败阻止使用当前 / 默认配置发送；失败状态不能仅靠 hover |
| 保存选择中 / 失败 | 保留旧值与轻量忙碌状态；失败显示原因，允许重试 | 不清空输入，不把整个输入区置灰，不假称保存成功 |
| CLI 不可用 / 附件阻止发送 | Composer 关联提示区显示具体原因 | 不能为了维持高度隐藏影响发送的错误；错误与设置应分层 |

后三类异常是后续生产实现的设计要求，v05 没有接真实目录与保存接口。原型目录只是示例：默认模型有五项，示例模型 B 有三项，用于验证档位变化和旧值保留。
