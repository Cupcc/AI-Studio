如何判断建设状态？

“已完成”指节点所列授权实现与必要技术验证已完成；人工功能验收由负责记录另行说明。“进行中”包含待补齐、验证、人工新增体验验收或后续发布；“未开始”包括已有方案或占位入口、尚无功能代码。外部依赖和 P1 不计入数量。节点数量不表示产品完成比例。筛选保留全景位置，淡化不匹配节点；数据流按匹配节点高亮步骤，清单仅显示匹配项。
