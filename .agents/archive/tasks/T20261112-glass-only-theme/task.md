## 目标

设置 → 外观不再提供主题选择，界面固定为毛玻璃。纯色外观保留为 macOS“降低透明度”时的无障碍回退。

## 范围

- 做：删除主题选项卡及其样式与预览 Token；外观偏好去掉 `theme` 字段和 `setTheme` IPC；实际外观只由“降低透明度”决定；旧版本保存的 `settings.appearance.theme` 不再读取；“毛玻璃背景”始终显示，降低透明度提示移到其下方；同步规格、FR、决定记录、设计规格和测试。
- 不做：改动纯色或毛玻璃的配色与几何；改动“降低透明度”的检测和窗口材质逻辑；清理数据库中旧的 theme 记录。

## 依据

- 用户 2026-11-12 对话：“删掉纯色这个ui”。随后从选项中选定“去掉设置里的纯色选项（推荐）”：主题只保留毛玻璃，纯色只在系统开启“降低透明度”时自动使用，已保存的纯色偏好迁移为毛玻璃。
- 新增 [DEC-31](<../../../../docs/07. Decisions.md#dec-31-设置移除纯色主题选项>)（部分取代 [DEC-12](<../../../../docs/07. Decisions.md#dec-12-外观主题与设置>)），修订 [FR-SET-002](<../../../../docs/02. Functional Requirements.md#fr-set-002-外观主题>)、[settings spec SET-C9](../../../../specs/settings/spec.md#12-已确认)。
