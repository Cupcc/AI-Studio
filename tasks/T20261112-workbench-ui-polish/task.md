# 工作台界面规范化

## 目标

按用户 2026-11-12 在对话中确认的设计，精简工作台宿主区域、规范选品页面的工具条，并统一字体与界面语言，使工作台达到可发布的观感。设计稿见[设计画布](https://claude.ai/artifact/FPDmPyEpuydS67DQWKCXM4)（私有，“定稿”页）。

## 范围

- 做：
  - 工作台宿主：删除预览区上方的“阶段行”“插件信息与备份”“包检查 / 页面连接”三行，改为右侧标题栏内的状态标记与“更多操作”菜单；新增“关于此工作台”面板、停用状态页、草稿与出错的呈现。
  - 去掉宿主的页面缩放；缩放只由带画布的页面自己提供。
  - 选品页面：流程条与操作改为画布上的悬浮条，修正流程标题被遮挡、提示压住节点和窄宽度下的排布。
  - 字体：界面与等宽字体优先使用系统字体，内置 IBM Plex 作为回退。
  - 界面文案统一为中文：导航分组、预设工作台名称、新对话入口与相关空态。
  - 导航：选中行与其他行等宽，“添加工作台”改为分组标题旁的加号。
- 不做：
  - 不改应用四种外观的颜色 Token，不改选品页面的绿色配色（仅新增一档用于画布上小字的加深色）。
  - 不改 Composer 的结构与行为（含思考强度指示与模型选择）、设置入口及其图标；唯一例外是模型名称不再带“（默认）”后缀。
  - 不改工作台清单、SDK、IPC 契约和存储。
  - 预设工作台页面内部的英文内容不在本轮翻译范围。

## 依据

- 用户 2026-11-12 对话：指出三行信息冗余难看；选择“单行标题 + 更多菜单”；流程条悬浮；停用用警示色；系统字体优先；文案统一中文；宿主不带缩放；并回复“按照你的设计执行”。
- [工作台规格 §9.7 生命周期与通用呈现](../../specs/workbench/spec.md#生命周期与通用呈现)、[§9.8 列表管理](../../specs/workbench/spec.md#98-fr-wb-001006008-工作台列表管理)、[§9.9 选品模板](../../specs/workbench/spec.md#选品模板)。
- [视觉方向 §1](../../design/visual-direction.md#1-高保真阶段待确定)：字体基线由本任务按用户决定调整。
- AC-06 仅作为回归范围：Project View 的预览、工具切换与 View Context 行为不变。

## 验收标准

- [ ] 工作台预览区上方不再出现三行宿主信息；页面内容紧接标题栏。（来源：用户 2026-11-12）
- [ ] 标题栏在正常、加载、出错、草稿、已停用五种状态下的呈现与设计一致，且四种外观下均可读。（来源：设计画布“状态变体”“细节”）
- [ ] “更多操作”菜单可完成编辑、重新加载、查看关于、停用 / 启用；停用项使用警示色。（来源：用户 2026-11-12）
- [ ] 宿主不再提供页面缩放；选品画布自带缩放可用。（来源：用户 2026-11-12）
- [ ] 选品页面的流程条和操作悬浮在画布上，流程标题不被遮挡；右侧区域最小宽度下不重叠。（来源：用户 2026-11-12；设计画布“定稿”）
- [ ] 界面字体优先系统字体。（来源：用户 2026-11-12）
- [ ] 导航分组、预设工作台名称与新对话入口为中文；内部 viewId 不变，已有 Project 的会话与状态可继续使用。（来源：用户 2026-11-12）
- [ ] Composer 的思考强度指示、模型选择行为与设置入口保持原样；模型名称不显示“（默认）”。（来源：用户 2026-11-12）
- [ ] 受影响的类型检查、单元测试与选中的 E2E 通过；界面由未参与实现的 Agent 在实际 Electron 应用中操作并截图验收。（来源：[Task Protocol](../README.md#acceptance)）

## 技术决定

- 停用不加二次确认：停用可随时启用且保留数据，警示色已足够提示。（Main Agent，2026-11-12）
- 保留现有操作名称“添加至当前项目”“应用更改”“编辑工作台”“停用工作台”“启用工作台”，不采用设计稿中的近义写法，减少文案与测试的无谓变动。（Main Agent，2026-11-12）
- 草稿说明与模板升级提示保留为标题栏下方的单行提示，不做成覆盖在页面上的浮层，避免遮挡页面自己的控件。（Main Agent，2026-11-12）
- 出错时保留“将错误填入对话”的名称，因为它只填写草稿、不自动发送。（Main Agent，2026-11-12）
- 模型按钮只显示模型名称；菜单里“跟随 CLI 默认”的那一项用右侧的“默认”小标记区分，不再用括号后缀，保留该选项的含义。（Main Agent，2026-11-12）
