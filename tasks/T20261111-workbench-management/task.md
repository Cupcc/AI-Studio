# 工作台列表管理

## 依据与范围

用户于 2026-11-11 指出 Workbench 缺少添加、删除、移动，并明确回复「对，apply 你的建议，执行」。本轮补齐左侧列表：添加预设和自定义工作台、重命名、同一项目内拖动排序、移除和恢复、删除草稿，以及重启恢复。添加入口参考 [DeepSeek Harness 调研](../../docs/references/deepseek-harness/README.md#2-来源事实左侧入口如何打开主面板)，放在列表下方并用浮层承载选项，打开时不改变已有列表和会话布局。来源为本次对话与 [workbench spec](../../specs/workbench/spec.md)，承接 FR-WB-001、FR-WB-006、FR-WB-008。

移除保留工作台状态、项目文件和会话，不停止运行中的 Session。删除草稿需确认，只删除宿主管理记录，保留文件与会话历史。跨项目移动、包卸载及页面内部内容编辑不在本轮范围。

## 实施与验收场景

| 场景 | 操作与预期 | 验证 |
|---|---|---|
| 添加 | 已有预设不重复添加；移除后可重新添加；AI 与模板创建保持可用 | 服务测试、Electron、实际界面 |
| 名称 | 预设、自定义与草稿可重命名；空白或过长名称拒绝；稳定 ID 与其他项目不变 | IPC、服务、界面 |
| 顺序 | 拖动和上移下移统一保存顺序；支持混排；重启保留 | 服务、Electron、实际拖动 |
| 移除恢复 | 移除当前项后选中相邻工作台；最后一项移除后进入新对话；恢复保留状态 | 服务、Renderer、Electron |
| 草稿删除 | 可取消或确认；已应用实例、文件、会话历史保留；旧草稿接口不可继续写入 | 服务、Electron、实际界面 |
| 隔离恢复 | 项目之间互不影响；重启保留名称、顺序和移除状态 | 服务、Electron |
| 错误 | 操作失败展示可理解错误并允许重试，不提前丢失列表或草稿 | Renderer |
