如何判断建设状态？

“已完成”仅指节点所列范围已有验证并经人工签收；“进行中”包括代码已实现、但待补齐、验证或签收；“未开始”包括已有方案或占位入口、尚无功能代码。外部依赖和 P1 不计入数量。节点数量不表示产品完成比例。筛选保留全景位置，淡化不匹配节点；数据流按匹配节点高亮步骤，清单仅显示匹配项。
