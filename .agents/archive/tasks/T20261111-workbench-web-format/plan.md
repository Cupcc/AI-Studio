# 网页插件格式统一计划

## 方案与分工

采用一个网页包格式和一个 iframe 运行方式。知识文件仍归宿主读取校验；页面通过公共能力声明订阅资源。Overview DOM 在包内，宿主只提供最小 Session 摘要和打开会话动作。SDK1 既有操作兼容。

候选设计比较后，采用资源随既有页面快照订阅的方案，避免新增多套 RPC 订阅和预设数据库种子；采纳另一方案的包可移植性证明。配置的候选模型不可用，采用继承模型，未进行跨模型评判。

| Agent | worktree | 写入范围 |
|---|---|---|
| Main | web-workbench-format | docs/specs、E2E、根 scripts 影响映射、任务与集成 |
| host_flow | web-workbench-format-host | desktop main/shared、五份预设 manifest.json 与相关测试 |
| ui_flow | web-workbench-format-ui | desktop renderer、网页包 JS/CSS/HTML、包生成与构建配置、相关测试 |
| rationale | 只读实现 | 独立验收、acceptance.md 与证据 |
