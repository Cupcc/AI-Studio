## 1. 推荐结论

**在 v05 稳定输入位置的基础上，优先改善连续操作：减少重复信息、保住未发送内容、就近解释当前状态，并提供明确的恢复入口。** v06 已把这些建议做成可操作原型。

继续沿用毛玻璃外观、IBM Plex Sans 正文 / 控件、IBM Plex Mono 代码与路径。正文主色 `#0d0d0d`、次级文字 `#262626`、说明 `#505050` / `#575757`、焦点 `#2563eb`；毛玻璃底色仍按 v04 半透明层叠。主列最大 720px，View 对话列最小 360px，控件行 32px；本轮不更换主题或字体。

Codex / Claude 的参考观察和限制继承 [v01 §2](layout-ux-review-v01.md#2-codex--claude-参考观察与判断)。其中 Claude 官方 Chat 截图的新对话输入框居中，v01 公开资料中的 Codex 示意图没有完整 Composer；原始评审时统一贴底是针对本产品工作流的建议，本次采用见 §6。后续本地参考另见[参考索引 §5](references/README.md#5-现有本地截图)，与历史公开资料分开记录。以下新增项主要来自本项目原型走查与既有规格。

## 3. 布局与状态

```text
顶栏：CLI 标识  会话标题…                  必要动作
正文：消息 / 起步示例 / View 说明
                                  [↓ 回到最新]  ← 仅离开底部时
┌──────────────────────────────────────────────────┐
│ 输入正文                                         │
│ [当前 View ×] [文件 ×]                            │
│ +                  模型⌄  ▂▅▇▉  [停止] [↑]      │
│ 按需显示：错误原因 / 目录提示           重试      │
└──────────────────────────────────────────────────┘
当前状态提示，空闲时不显示快捷键说明；发送按钮悬停 / 聚焦时提示 Enter 发送 / Shift + Enter 换行。
```

- New Chat、已有 Session 和 View 共用底部结构。辅助行位于输入框外，因此 v06 的框体底边比 v05 上移 24px；辅助行底边距内容面板底部 20px，新建到发送后的位置一致。
- 模型与思考保持相邻，控件直接显示当前值；目录错误时才显示状态提示，原型不模拟真实请求快照。
- `+` 展开为可滚动的 Add 面板，先按来源分类再列出能力；每项可用图标、名称与描述快速扫描。Files 进入工具面板，Skill 直接加入当前草稿，Plugin 无 catalog 时只显示禁用空状态。
- 错误和目录提示位于控制行之下；正文、标签、状态可增高，模型 / 思考 / 发送的顺序保持稳定。不能以视觉整齐为由隐藏影响发送的原因。
- View 最近对话是轻量列表，继续使用既有最多三条的规则；不添加新的导航层级。

| 输入状态 | 就近反馈 | 操作 |
|---|---|---|
| 空闲 | 不显示快捷键说明；发送按钮悬停 / 聚焦时提示 | 有正文即可发送 |
| Codex 模拟运行中 | 正在处理 · 可补充当前任务 | Send / Stop 独立，空输入时 Send 禁用 |
| 当前 Provider 不支持运行中输入 | 运行中不可追加输入 | 保留草稿，禁用 Send；本原型 Claude fixture 采用此分支，不代表其实际发布能力 |
| 等待回复 | 等待回复 | 支持文字回复与 Stop；有附件时说明需要先移除 |
| 草稿 CLI 未登录 | 指明 CLI 未登录 | 禁用 Send，保留正文与标签 |
| 模型目录读取失败 | 显示“目录不可用 · 可发送”，提供“重试” | 选择器禁用但当前值保留；恢复后焦点回模型按钮 |
| 已存 effort 未被目录列出 | 保留值，常显“目录未列出”，提供“使用默认” | 不静默重置；目录不完整不等于原生不可调用 |
| 发送失败 | 发送失败，输入和附件已保留；“重试发送” | 不创建模拟 Session；重试成功后才清空对应草稿 |

## 4. 连续操作与键盘

- 示例只填入没有非空白正文的草稿，不直接发送；已有附件保留。重新点击 New Chat 回到已有草稿。
- 从 Files 添加文件只影响当前可见草稿 / Session。切到 View 不携带 New Chat 附件；发送清空当前草稿，不动其他草稿。
- 模型、思考、加号使用普通按钮展开：`aria-expanded` 与 `aria-controls` 描述展开关系，Tab / Enter / Space 可操作；额外支持方向键和 Home / End 选择位置。选择或 Esc 关闭后回到触发按钮。
- 持续的状态播报区域放在重绘容器外，只在状态说明发生变化时更新；不随每段流式文字反复播报同一输入提示。
- 面向开发者的空闲 Composer 不常驻快捷键说明。发送按钮通过悬停 / 键盘聚焦提示 Enter 发送、Shift + Enter 换行；输入 `@`、`/`、`$` 时显示对应候选列表，方向键、Enter / Tab 选择，Esc 关闭。
- 返回最新按钮不占消息列布局；向上阅读时保留当前会话的滚动位置，主动发送或点击按钮回到底部。

按钮展开语义参考 [WAI Disclosure Pattern](https://www.w3.org/WAI/ARIA/apg/patterns/disclosure/)，状态不依赖抢夺焦点且避免重复播报参考 [WCAG 2.2 Status Messages 说明](https://www.w3.org/WAI/WCAG22/Understanding/status-messages.html)（2026-10-20 查阅）。本轮做了键盘与 DOM 自检，不宣称完整无障碍符合性。
