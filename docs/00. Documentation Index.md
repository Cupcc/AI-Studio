## 文档规则

本节只约定 `docs/` 下的编号文档；仓库通用的写作与确认规则见 [AGENTS.md](../AGENTS.md)。

- 命名：`docs/NN. Topic.md`，`NN` 为两位递增编号，`Topic` 用英文。新增编号文档时在本索引登记。
- 文档信息：每份文档开头保留 `文档信息` 表，其中 `文档状态` 取 `草稿` 或 `已确认（YYYY-MM-DD）`；[07. Decisions](<07. Decisions.md>) 逐条标注状态。确认状态以各文档自身记录为准，索引和其他文档不重复。
- 审阅：本目录的每次改动都由人审阅 diff。
- 编号：`FR-*`、`AC-*` 编号保持稳定；FR 的引用约定见 02 第 1 节，DEC 编号见 07 规则。
- 冲突优先级：01 > 02 > 03 / 04 / 05 > `specs/` > `design/`，冲突时以前者为准，并修正后者或在其未决问题中记录（2026-10-10 确认）。01～05 开头所说“文档索引定义的优先级”即指本条。
- 一致性：行为变化先对照 01、02，再同步 03、04、05 中受影响的内容，并核对需求引用与 05 第 3 节的 FR ↔ AC 矩阵。需求与实现存在差异时，回到负责该主题的文档核对，并在相关任务中记录问题。
